Découpage relevé image par image (capture d'écran Instagram envoyée le 12/10/2026).

| Temps | Ce qu'on voit | Technique |
|---|---|---|

## Pourquoi ça fait « pépite »

1. **Une caméra continue** pendant 6,5 s : on entre dans le téléphone, l'interface devient un décor 3D. Zéro coupe, zéro fondu.
2. **Rendu physique** : vrai verre, vraies réflexions, profondeur de champ, flou de mouvement long, une seule grosse lumière colorée + brume. Rien ne ressemble à du CSS.
3. **Tout est calé sur la musique** : chaque mot arrive sur une syllabe, chaque changement de monde (bleu → blanc → néon noir) tombe sur un temps.
4. **Trois mondes, trois palettes**, chacun avec une seule technique (couches UI / typo noire sur blanc / néon). Pas de mélange.
5. **La typo est la star** : énorme, 1 à 3 mots à l'écran, jamais un paragraphe.
6. **Une chute** (les barreaux) puis le logo tenu longtemps.

- Monde 3 (noir, néon orange) : la promesse « LE TEMPS D'ÉCRAN SE GAGNE », puis la chute visuelle (ex. le cadenas qui s'ouvre / le téléphone qui se déverrouille).
- Logo cyan/orange tenu 3 s, CTA en dernière seconde.
